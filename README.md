entered in the make.fun competition
[news-image-20261119](https://make.fun/c/news-image-20261119).

Lead story: Trump, Xi and Putin meet in Shenzhen — the first-ever trilateral
summit of the three presidents, on the sidelines of the APEC summit. Also
covered: GTA VI goes on sale worldwide, the US–Iran exchange of fire widening
to Kuwait and Bahrain, the Fed minutes pointing to further rate rises, the EU's
€45bn loan proposal for Ukraine, the Democrats nominating Hakeem Jeffries for
Speaker, Nvidia halting H-series chip shipments to China, and Cyclone Akvan
bearing down on India's east coast.

## How it runs

`main.ts` (Node 22, standard library only) copies the `entry.png` in this
repository to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`).
It runs with no network and writes identical bytes on every run.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
